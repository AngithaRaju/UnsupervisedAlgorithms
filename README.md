In this assessment, KMeans and Hierarchical Clustering were implemented on the Iris dataset using the four numerical features. The features were standardized to ensure that differences in their scales did not disproportionately affect the clustering results.

KMeans grouped the flowers by assigning them to their nearest cluster centroids, while Hierarchical Clustering grouped them through successive merging of similar data points. PCA was used to visualize the resulting clusters in two dimensions, and a dendrogram was used to examine the hierarchical relationships.

Both algorithms help identify patterns and similarities in the Iris dataset without using species labels during clustering. Their results may differ because they use different approaches to forming clusters. Overall, this exercise demonstrates how unsupervised learning can be applied to explore and understand data.
